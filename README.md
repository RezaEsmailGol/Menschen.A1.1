# Deutsch Trainer — Menschen A1.1 Companion

یک اپ تمرینی React/Vite برای همراهی با کلاس آلمانی و کتاب Menschen A1.1.

## امکانات
- فلش‌کارت با ذخیره محلی
- افزودن/خروجی/ورود فلش‌کارت JSON
- تلفظ آلمانی با Web Speech API مرورگر
- تمرین شنیدن و تایپ
- اعداد 0 تا 20
- الفبای آلمانی
- تمرین صرف افعال kommen / lernen / arbeiten
- کلمات و نکات تلفظی جلسه اول کلاس
- ذخیره پیشرفت در localStorage
- رابط موبایل‌محور و فارسی

## اجرا
```bash
npm install
npm run dev
```

برای نسخه production:
```bash
npm run build
npm run preview
```

## نکته حق نشر
این پروژه متن کامل کتاب Menschen را شامل نمی‌شود. محتوای اولیه بر اساس یادداشت‌های کلاس و عبارت‌های آموزشی کوتاه ساخته شده و می‌توانی کارت‌ها و تمرین‌های درس‌های بعدی را خودت وارد کنی.
